================================================================
   خطوات نشر ZyncIT Extension على Chrome Web Store
================================================================

📋 المتطلبات الأساسية:

1. حساب Google Developer
2. دفع رسوم التسجيل: $5 (لمرة واحدة فقط)
3. ملف ZIP للإكستنشن ✅ (موجود: ZyncIT-Extension-v1.0.zip)
4. أيقونات بأحجام مختلفة
5. صور توضيحية (Screenshots)

================================================================
   الخطوة 1: التسجيل كمطور
================================================================

1. اذهب إلى:
   https://chrome.google.com/webstore/devconsole

2. سجل دخول بحساب Google

3. اضغط على "Pay registration fee" وادفع $5
   (هذا الدفع لمرة واحدة فقط)

4. أكمل معلومات المطور:
   - اسم المطور
   - البريد الإلكتروني
   - الموقع الإلكتروني (اختياري)

================================================================
   الخطوة 2: تحضير الأصول المطلوبة
================================================================

✅ الأيقونات (Icons):
   - 16x16   ✓ (موجودة)
   - 48x48   ✓ (موجودة)
   - 128x128 ✓ (موجودة)

📸 Screenshots مطلوبة:
   - الحجم: 1280x800 أو 640x400
   - العدد: 1-5 صور توضيحية
   - تظهر واجهة الإكستنشن وميزاته

🖼️ Promotional Images (اختياري):
   - Small tile: 440x280
   - Large tile: 920x680
   - Marquee: 1400x560

================================================================
   الخطوة 3: رفع الإكستنشن
================================================================

1. اذهب إلى Chrome Web Store Developer Dashboard:
   https://chrome.google.com/webstore/devconsole

2. اضغط "New Item"

3. ارفع ملف ZIP: ZyncIT-Extension-v1.0.zip

4. املأ المعلومات المطلوبة:

   📝 Store Listing:
   ----------------
   Product name: ZyncIT
   
   Summary (132 characters):
   Sync your Android SMS, calls, and notifications to Chrome. 
   Send SMS from your browser seamlessly.
   
   Description:
   ZyncIT allows you to sync your Android device's SMS messages, 
   call logs, and notifications directly to your Chrome browser. 
   
   Features:
   • View SMS messages in real-time
   • See call history with contact names
   • Access notifications from any app
   • Send SMS directly from browser
   • Automatic sync with Firebase
   • Dark mode support
   
   Requirements:
   • Android app installed on your device
   • Same account logged in both places
   
   Category: Productivity
   
   Language: English (يمكن إضافة Arabic لاحقاً)

5. ارفع Screenshots:
   - التقط 3-5 صور من الإكستنشن وهو يعمل
   - أظهر:
     * قائمة الرسائل
     * قائمة المكالمات
     * إرسال رسالة جديدة

6. Privacy Practice:
   - Single Purpose: Sync device data
   - Permissions Justification:
     * storage: Save user preferences
     * identity: User authentication
   - Privacy Policy URL: (يفضل إنشاء صفحة)

================================================================
   الخطوة 4: المراجعة والنشر
================================================================

1. اضغط "Submit for Review"

2. Google ستراجع الإكستنشن (عادة 1-3 أيام)

3. ستصلك رسالة بالموافقة أو طلب تعديلات

4. بعد الموافقة، اضغط "Publish"

5. سيكون الإكستنشن متاح على:
   https://chrome.google.com/webstore/detail/[EXTENSION_ID]

================================================================
   الخطوة 5: التحديثات المستقبلية
================================================================

لرفع نسخة جديدة:

1. عدّل رقم الإصدار في manifest.json:
   "version": "1.1"

2. اعمل ZIP جديد

3. من Dashboard → اختر الإكستنشن → Upload Updated Package

4. اكتب التغييرات في "What's new"

5. Submit for Review
